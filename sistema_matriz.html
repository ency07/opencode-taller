¿Qué quiero hacer?

No necesitas conocer todo el sistema. Busca tu situación, copia el comando y pégalo en el chat.

ARCHITECT→SERIE→EXPLORE→DEVELOP→MARKET→MASTER

1. Inicializar un chat nuevo

Pégalo una sola vez al comenzar un chat.

2. Tengo una idea, pero no tengo estructura

Usa /ARCHITECT.

3. NO tengo una serie y quiero crear una

Este es el comando que faltaba: /SERIE.

4. Ya tengo una serie y quiero explorar diseños

Usa /EXPLORE.

5. Ya elegí una dirección y quiero desarrollarla

6. Quiero MEN / WOMEN / KIDS

Son tres artes nuevos, no tres mockups.

7. Ya tengo el arte aprobado y quiero producirlo

8. Tengo una imagen de referencia

Adjunta la imagen y usa /ARCHITECT.

9. Quiero A / B / C del mismo arte

10. Opcional: optimizar el arte para DTF

/DTF-CHECK solo se usa cuando tú lo pidas. No se aplica automáticamente.
