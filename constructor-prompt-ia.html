🧠 Constructor de Prompt IA MODO BANCOS

Completa el contexto del lote y el constructor arma el prompt limpio para tu IA. Formato de salida: taller-pod-motif-candidates (schemaVersion 1). Aquí no se gasta token: solo se arma texto.

1. Contexto del lote de candidatos

Mercado al que pertenecen los candidatos. Evita mezclar mercados en un mismo lote.
Lenguaje visual del candidato. Ej: "Deportiva / Sports", "Minimal Modern", "Y2K / Cyber". Para estilos de producción (DTF/sublimación) usar el Motor de lenguajes.
Cualquier subnicho es válido; si la familia ya es una familia con banco propio, usa su id (ej: deportiva_sports).
Producto físico que se imprimirá. Define la zona de aplicación del candidato.
Audiencia a la que va dirigido el candidato. Si se mezcla, el prompt debe separar audiencias.
El JSON de salida incluye "idioma". El texto visible de las frases va en este idioma.
Tono de la propuesta. Si el mercado lo pide, se combina con la audiencia.
